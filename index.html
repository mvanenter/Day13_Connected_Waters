DATA & METHODS

Behind the network

Based on the REC2 river-network extract exported in ArcGIS Pro. A Python graph trace followed each reach's NextDownID values upstream from outlet 593451.

Recorded QA/QC

  • 593,517 national source reaches checked for identifier uniqueness and downstream references.
  • 2,706 connected Ashley/Rakahuri reaches extracted and verified.
  • 2,705 downstream links in the extract; zero broken references or cycles.
  • All 2,706 reaches have an attribute-defined path to the chosen outlet.
  • Geometric endpoint checks found no gaps greater than 1 metre.
  • Total network length: 2,086.75 km (geodesic centreline sum), not the main river's length.

Data interpretation

The network is suitable for exploring modeled river connectivity. It does not establish present-day surface-water movement across braided channels, dry reaches, or diversions. Cumulative catchment area is a source attribute, not a sum across reaches. Per-trace lengths use the exported NZTM2000 length_km attributes; the 2,086.75 km overall network metric comes from ArcGIS geodesic measurement.
